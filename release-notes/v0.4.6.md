## What's Changed

### Single-Binary Release, Binary Size Diet & SP-13 Move-Cache Parity
- **~70% Smaller Release Archives**: Removed the duplicate `bitefoundry-onedrive` fat-LTO binary target in favor of `argv[0]` symlink/copy dispatch, and enabled `opt-level = "s"` + `panic = "abort"` in `[profile.release]`.
- **SP-13 Move-Cache Parity**: Unified CLI `mv`, MCP `move_or_rename_item`, HTTP `PATCH`, and TUI rename onto shared uncached-folder lookup and `upsert_drive_item_after_move` cache updates (with E2E regression coverage).
- **Hardening & Lint Cleanup**: Boxed oversized enum variants (`Overlay`, `DriveDeltaChange`), hardened production `unwrap()` sites (including `serve` download serialization), and resolved all Clippy warnings (`-D warnings` clean).
- **Dependency & Packaging Diet**: Upgraded `ratatui` to `0.29`, `dirs` to `6`, and trimmed `bitefoundry-html` `resvg` features; removed direct `scraper`, `uuid`, `futures`, and unused `crossterm/event-stream`, moved `tempfile` to dev-dependencies, added optional Cargo feature gates (`html-js`, `svg-graphics`, `desktop-notify`), and externalized `assets/demo.gif` to `bitefoundry.dev`.
