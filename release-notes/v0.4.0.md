## Files and lists

- Discover a site's lists using `sharepoint lists ls --site-id <SITE_ID> --json` or the MCP `list_lists` tool. Use the returned list ID for column and row operations.
- Conditional uploads reject explicitly empty ETags. Empty-file uploads now send the supplied `If-Match` header. Ambiguous site and library names return matching candidates so callers can choose the intended ID.
- MCP clients can initialize and list tools before signing in. File commands handle names beginning with a hyphen.

## Compatibility

- Scripts using `--json` can read `error.code` and `error.message` from stdout when a command fails at runtime. The process exits with status 1.
- Default file listings and write responses omit the temporary `download_url`. Use the download command when you need the file contents.
