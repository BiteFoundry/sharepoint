## What's Changed

### Document Library Custom Columns, `omitted` Surfacing & Selective `fields` Projection
- Expanded `get_item` / `get_item_by_path` with `$expand=listItem($expand=fields)` (with transparent fallback on unsupported personal drives) to capture SharePoint Document Library custom columns, `description`, and file hashes (`sha256_hash`/`quick_xor_hash`).
- Surfaced populated custom columns in `omitted.list_item_fields` on compact `get_file_info` and added selective `fields: [...]` projection (matching standard fields and case-insensitive custom column names, plus `missing_fields`).
- Enriched `list_columns` to preserve `description`, `required`, inferred `column_type`, and `choices`.

### Symlinked `$HOME` & npm Postinstall Hardening
- Fixed `scripts/postinstall.mjs` main-module guard via `fs.realpathSync` for symlinked `$HOME` / npm prefixes.
- Canonicalized daemon UDS hashes and isolated `XDG_RUNTIME_DIR` fallback sockets per profile.
- Preserved dotfile symlinks in `write_atomic` (while refusing `0600` secret symlinks), expanded `~/` on `SHAREPOINT_CONFIG_DIR`/`SHAREPOINT_DATA_DIR`/`TEAMS_CONFIG_DIR`, and resolved symlinked binaries in `updater.rs`.
