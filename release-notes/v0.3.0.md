File details from `sharepoint info <file> --json` and MCP `get_file_info` default to compact results with omission metadata. Pass `--json --full` or `compact: false` for expanded details.

List rows return 50 items by default. Use the continuation cursor with the same site, list and field selection to read the remaining rows. Version history also reports when more entries are available.

Drive discovery covers sites beyond the first ten and reports incomplete discovery. Tree and directory results indicate when additional children are available.
