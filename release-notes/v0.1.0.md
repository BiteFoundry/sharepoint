# `@bitefoundry/sharepoint` v0.1.0

Initial standalone release of the unified **Microsoft SharePoint & OneDrive** terminal client & AI agent toolkit (`sharepoint`, `sp`, `onedrive`, `od`).

## Highlights
- **Dual-Persona Single Binary**: `sharepoint` / `sp` boots into SharePoint Sites & Document Libraries; `onedrive` / `od` sets `SHAREPOINT_PERSONA=onedrive` to boot directly into Personal OneDrive.
- **Full Microsoft Graph Drives & SharePoint Engine**: `/me/drive`, `/recent`, `/sharedWithMe`, `/sites?search=*`, `/me/followedSites`, `/sites/{id}/drives`, paginated folder children (`@odata.nextLink`), path-based addressing, version history, sharing links, redirect-auth-stripped downloads, simple `< 4 MiB` PUT uploads, resumable chunked `>= 4 MiB` upload sessions, `mkdir`, rename/move, delete, drive & cross-site search.
- **Minimal-Chrome 3-Pane TUI**: 5-palette theme, 80ms CSI/DA1/Kitty graphics probing + Lanczos3 + Sixel Floyd-Steinberg dithering, live inline image & text/code inspector, `Ctrl+V` clipboard PNG upload, `Ctrl+F` file picker with `zoxide`, `u`/`h` Link Extractor, Command Palette (`Ctrl+P`), Settings (`Ctrl+,`), Context Menu (`.`), desktop notifications, and shared IPC sync daemon.
- **Agent-Native CLI, HTTP API (`:8790`) & MCP Server (16 tools)**: structured `--json` outputs, safe non-interactive deletion guards (`--yes` / `confirm: true`), and SQLite WAL + FTS5 cache with Korean `<3` char `LIKE` fallback.
