## Local HTTP API

- `sharepoint serve` now always requires a Bearer key. Without `--api-key` it generates a random key at startup and prints it once to stderr. Pass `--api-key <secret>` for a stable key, or `--allow-keyless` to serve without one on a loopback address.
- A non-loopback `--bind` requires `--api-key`. Requests whose `Host` header does not name the server get `403`; add a reverse-proxy name with `--allowed-host`. CORS allows loopback origins and exact `--cors-origin` values only.
- On a server started without a key, `local_path` uploads and `dir` downloads return `403` unless it was started with `--allow-local-paths`.

## Files and sync

- `--site` finds sites by searching Microsoft Graph for the query instead of matching only the first page of results. A sidebar site opens on the first activation.
- Downloads no longer stop after 60 seconds. A failing pre-authenticated download URL falls back to the Graph content endpoint, and transient failures are retried before any data is written.
- A zero-byte upload with `--conflict rename` no longer overwrites an existing file; it takes the next free name.
- Folders with more than 200 items say so in the folder header. Press `L` to load 200 more.
- Long change feeds resume where they stopped instead of falling back to a partial resync. A resync re-checks the open folder and the folders above it.

## Sign-in, configuration and networks

- `share_m365_auth = false` is honoured when a token is refreshed.
- Saving a setting writes only that setting. Values from environment variables and the detected image protocol are no longer copied into `config.toml`.
- HTTPS connections trust the operating system's certificate store in addition to the bundled roots. Set `SHAREPOINT_EXTRA_CA_PEM` (or `SSL_CERT_FILE` / `NODE_EXTRA_CA_CERTS`) for a corporate proxy CA. Unknown-issuer failures explain these options.
- MCP tool descriptions state how many Graph requests a call makes and which argument avoids them.

## Compatibility

- Scripts that call `sharepoint serve` without `--api-key` must read the generated key from stderr, pass `--api-key`, or add `--allow-keyless`.
- Clients that send `local_path` or `dir` to a keyless server must add `--allow-local-paths` or send file content instead.
