## What's Changed

### Sync & Discovery Parallelization
- Parallelized `bootstrap_sharepoint` and `sync_core_discovery` across 6 independent streams (`get_me`, personal drive + delta, followed + searched sites with bounded `buffered(4)` drive discovery, Recent, SharedWithMe, and active folder delta).
- Parallelized `sync_sites_once`, Tier 2 410/overflow ancestor folder resyncs (`buffered(4)` after `?token=latest`), `resolve_site`, `fetch_sites`, `discover_drives`, `doctor --online`, `mv` source/destination resolution, and recursive `tree` sibling fetches (`Semaphore(4)`).

### Graph Fallback & Metadata Caching
- Memoized per-drive `$expand=listItem($expand=fields)` 400/501 fallback on `GraphClient` so personal OneDrive drives skip repeated failing probes while SharePoint libraries keep expanding fields.
- Cached drive root IDs for read/sync callers (`get_drive_root_id_cached`), cached SharePoint list `/columns` schemas across `update_list_item_field` calls (with live refresh on miss), and reused SQLite drive/root-path hints in `resolver.rs`.

### TUI Upload & Creation Responsiveness
- Updated `UiMsg::FolderCreated` and `UiMsg::ItemUploaded` to optimistically insert, select, and preview freshly uploaded text/image bytes immediately in the Inspector with zero `/content` re-downloads.

### Test Hardening
- Guarded unit-test config and draft persistence from mutating the host user config directory and aligned the MCP hint e2e assertion.
