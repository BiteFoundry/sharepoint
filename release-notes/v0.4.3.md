## What's Changed

### Terminal Image Preview Quality & Protocol Detection
- Replaced fixed low-resolution downsampling and stretched aspect-ratio math with terminal cell-geometry sizing and unified protocol detection across Kitty, iTerm2, Sixel, and half-block renderers.

### Native HTML/SVG/Canvas & Embedded Graphics Rendering
- Eliminated raw HTML/SVG/script source leaks in SharePoint file/HTML previews via pure-Rust `bitefoundry-html` (`resvg 0.50` + `tiny-skia` + `base64`) for inline `<svg>`, `<canvas>`, and `data:image/*` graphics, with an explicit `[o: Browser]` banner for external `<script src>` content.

### Unified Markdown Rendering & `.md` Preview
- Replaced the legacy 1,800-line custom markup parser with `pulldown-cmark 0.13` via `bitefoundry-html::markdown` and enabled rich `.md` previewing in Drive view.

### Width-Aware Text Wrapping & Narrow Viewport Polish
- Migrated Drive view notices, narrow-viewport file rows (down to 32 columns), and raw preview truncation banners to display-width-aware wrapping without clipping.

### TUI Overlay Dispatch, Sort Sync & Inspector Scroll
- Fixed overlay dispatch re-entry, modal backdrop isolation, sort synchronization, and inspector scrolling, and added Docker / MCP Registry (`server.json`) packaging.
